19 Power and Non-Parametric Tests for Categorical Data

19.1 Introduction

Recall from Section 15 that the power of a hypothesis test is the probability that the null hypothesis will be rejected when the alternative hypothesis is true and that the sample size, significance level, and effect size are used together to determine its value. There are power functions corresponding to the various types of parametric, categorical tests.

We will use worked examples to see how to use functions (from the pwr package) in R to assess the power of parametric tests for categorical data.

In Section 19.3, we will lean about Fisher’s exact test, which is a non-parametric test for testing if the categorical variables in a two-way table are associated or not, and can be used when conditions for parametric versions covered in Section 18 are not met.

19.2 Worked Examples 

library(pwr) ##load package for various power functions

19.2.1 GOF Test for Categorical Data

It is thought that when given a standard treatment, 50% of individuals with hypertension will show a marked decrease in blood pressure, 25% of individuals with hypertension will show a moderate decrease in blood pressure, 10% of individuals with hypertension will show a slight decrease in blood pressure, and 15% of individuals with hypertension will show no change in blood pressure. A random sample of 200 individuals with hypertension will be selected and each will be given a new treatment to test if there is evidence that individuals react differently to this treatment than to the standard treatment. What is the power if there is a small effect size between the treatments? What is the minimum sample size to detect a small effect size between the treatments with at least 0.8 power?

## Calculate the power
pwr.chisq.test(w = 0.2, N = 200, df = 3, sig.level = 0.05)
## 
##      Chi squared power calculation 
## 
##               w = 0.2
##               N = 200
##              df = 3
##       sig.level = 0.05
##           power = 0.6541111
## 
## NOTE: N is the number of observations
## w for effect size.
## N for sample size
## df is 3 since we have 4 levels

The power is about 0.654 for a small effect size.

## Determine the sample size required for power of 0.8
ceiling(pwr.chisq.test(w = 0.2, df = 3, sig.level = 0.05, power = 0.8)$N)
## [1] 273

We need a sample of at least 273 to achieve 0.8 power with small effect size.

19.2.2 Chi-Squared Test for Two-Way Table

A sample of 400 individuals is to be randomly drawn to determine whether there is a significant association between gender and education level. The individuals will be classified into two genders and four education levels. What is the power for this test when there is a small association?

## Calculate the power
pwr.chisq.test(w = 0.2, N = 400, df = 3, sig.level = 0.05)$power
## [1] 0.9340886
## df is (2-1) times (4-1) = 3

The power is about 0.934 to detect a small association between gender and education level.

ceiling(pwr.chisq.test(w = 0.2, df = 3, sig.level = 0.05, power = 0.8)$N)
## [1] 273

We need at 273 observations to achive 0.8 power to detect a small association between gender and education level.

19.2.3 One-Sample Z-Test

A student hears that 10% of the U.S. population is left-handed and wants to determine if his school has a lower proportion than the general population. To investigate, he plans to randomly sample 200 of his fellow students. What is the power of the student’s test when the true proportion is slightly lower? What is the minimum

## Calculate the power
pwr.p.test(h = -0.2, n = 200, sig.level = 0.05, alternative = "less")$power
## [1] 0.881709

The power to detect a small difference is about 0.882.

## Determine the sample size required for power of 0.8
ceiling(pwr.p.test(h=-0.2, sig.level=0.05, power=0.8, alternative="less")$n)
## [1] 155

He needs a sample size of at least 155 to detect a small difference with at least 0.8 power.

19.2.4 Two-Sample Z-Test

The sample poverty rate in 2001 is to be measured using a sample of 500 individuals. The sample poverty rate in 2002 is to be measured using a sample of 600 individuals. What is the power of the test for whether there is significant evidence that the U.S. poverty rate changed from 2001 to 2002 when the effect size is small? If the sample size from 2001 remains 500, what does the sample size for 2002 need to be to yield a power of 80%?

## Calculate the power
pwr.2p2n.test(h = 0.2, n1 = 500, n2 = 600, sig.level = 0.05, alternative = "two.sided")$power
## [1] 0.9103523

The power to detect a small effect size is 0.910.

## Determine the sample size required for power of 0.8
ceiling(pwr.2p2n.test(h = 0.2, n1 = 500, sig.level = 0.05, power = 0.8, alternative = "two.sided")$n2)
## [1] 323

The minimum sample size in 2002 to achieve power of at least 0.8 is 323.

19.3 Fisher’s Exact Test

The Fisher’s exact test tests whether there is association between independent categorical variables that can be summarized in a two-way table with fixed marginal totals. Before we go any further, we need to learn about the hypergeometric distribution, since Fisher’s exact test is based on this distribution.

19.3.1 The Hypergeometric Distribution

This is a classical example used to demonstrate the hypergeometric distribution. I have adjusted the notation to better match the arguments used in R and so it is different from the classical notation:

  • Imagine an urn with \(m\) white balls and \(n\) black balls.
  • Sample \(k\) balls from the urn without replacement.
  • Let \(X\) be the number of white balls in the sample.
  • \(X\) follows a hypergeometric distribution with parameters \(m, n, k\), i.e. \(X \sim H(m, n, k)\).

This information is represented in the following two-way table:

Table 19.1: Two-Way Table for Hypergeometric Distribution
White Black Total
Sampled \(X\) \(k\)
Not sampled \(N - k\)
Total \(m\) \(n\) \(N = m+n\)

With \(X \sim H(m, n, k)\): \(X\) is the random variable that denotes the number of white balls in a sample of size \(k\), drawn without replacement from an urn with \(m\) white balls and \(n\) black balls. The PMF of \(X\) is

\[\begin{equation} P(X=x) = \frac{\binom{m}{x} \binom{n}{k-x}}{\binom{m + n}{k}} \tag{19.1} \end{equation}\]

To find the probability from equation (19.1), we can use dhyper(x, m, n, k). For example, if we have this table

Table 19.2: Two-Way Table for Hypergeometric Distribution
White Black Total
Sampled 9 1 10
Not sampled 6 4 10
Total 15 5 20

The probability of having 9 white balls from 10 drawn without replacement from an urn with 15 white balls and 5 black balls is

dhyper(9, 15, 5, 10)
## [1] 0.1354489

Now we are ready to talk more about Fisher’s exact test.

19.3.2 Hypotheses

The null and alternative hypotheses are the same as the chi-squared test for two-way tables:

  • The null hypothesis states that there is no association between the two variables.
  • The alternative hypothesis states that there is some association between the two variables.

19.3.3 Test Statistic and P-value

There is not a calculated test statistic. Instead, the probability of observing values that indicate a more extreme association that what is shown in the given two-way table is calculated as the p-value.

So we assume the null hypothesis is true (no association), then constrain the row and column totals in the two way table (keep them fixed).

We then consider all possible two-way tables that satisfy the row and column totals, and calculate the relevant probability for each possible table.

The p-value of Fisher’s exact test is the sum of the probabilities for all tables having a probability equal to or smaller than that observed.

For example, we observe the following data presented in table 19.2.

Given the row and column totals, the only possible values for \(X\) are 5, 6, 7, 8, 9, 10. The corresponding probabilities are

dhyper(5, 15, 5, 10)
## [1] 0.01625387
dhyper(6, 15, 5, 10)
## [1] 0.1354489
dhyper(7, 15, 5, 10)
## [1] 0.3482972
dhyper(8, 15, 5, 10)
## [1] 0.3482972
dhyper(9, 15, 5, 10)
## [1] 0.1354489
dhyper(10, 15, 5, 10)
## [1] 0.01625387

so the p-value is

sum(dhyper(5, 15, 5, 10) + dhyper(6, 15, 5, 10)
    + dhyper(9, 15, 5, 10) + dhyper(10, 15, 5, 10))
## [1] 0.3034056

Next, we go over a worked example.

19.3.4 Worked Example

A research team made up of advocates for social justice and psychologists designed an experiment where two companies were sent a batch of 12 resumes for evaluation. Each resume was returned either with an invitation for an interview or not. Two versions of all 12 resumes were created: one with a non-European sounding name and one with a European-American sounding name. The version sent to each company was randomized. Is there evidence of ethnic bias?

Table 19.3: Two-Way Table for Worked Example
Invitation None
Non-Euro 2 10
Euro 8 4

The null hypothesis is that there is no association between the sound of the last name and whether the resume resulted in an invitation or not. The alternative hypothesis is that there is an association between the sound of the last name and whether the resume resulted in an invitation or not.

To find the p-value in R, we need to create a matrix that represents the information in Table 19.3, and then apply the fisher.test() function to the matrix.

exp.res <- matrix(c(2,10,8,4), nrow = 2, ncol = 2, 
                  byrow = TRUE)

fisher.test(exp.res)
## 
##  Fisher's Exact Test for Count Data
## 
## data:  exp.res
## p-value = 0.03607
## alternative hypothesis: true odds ratio is not equal to 1
## 95 percent confidence interval:
##  0.008101526 0.896925044
## sample estimates:
## odds ratio 
##  0.1121872

The p-value is 0.036, so we reject the null hypothesis. The data provide evidence of some association between the sound of the last name and whether the resume resulted in an invitation or not.

We could have listed all possible two-way tables with the same row and column totals as Table 19.3 and find each of their corresponding probabilities based on the hypergeometric distribution, but there are 11 such tables.

19.3.5 Larger Tables

With a two-way table, the number of possibilities with the same row and column totals can get large easily. For larger tables (more than 2 rows or 2 columns), the number of possibilities is large.

With large tables, Monte Carlo simulation can be used to generate the p-value using the default 2,000 replicates by specifying TRUE for the simulate.p.value argument. The number of replicates used can be set with the B argument.

Consider this example: The research team instead asks both companies for whether the candidate would definitely receive an invitation for an interview, might receive an invitation for an interview, or definitely would not receive an invitation for an interview.

Table 19.4: Two-Way Table for Larger Table
Invitation Possible None
Non-Euro 2 3 7
Euro 8 1 3 
exp2.res <- matrix(c(2,3,7,8,1,3), 
                   nrow = 2, ncol = 3, 
                   byrow = TRUE)

fisher.test(exp2.res)
## 
##  Fisher's Exact Test for Count Data
## 
## data:  exp2.res
## p-value = 0.05993
## alternative hypothesis: two.sided
fisher.test(exp2.res, simulate.p.value = TRUE)
## 
##  Fisher's Exact Test for Count Data with simulated p-value (based on
##  2000 replicates)
## 
## data:  exp2.res
## p-value = 0.05047
## alternative hypothesis: two.sided
fisher.test(exp2.res, simulate.p.value = TRUE, B = 10000)
## 
##  Fisher's Exact Test for Count Data with simulated p-value (based on
##  10000 replicates)
## 
## data:  exp2.res
## p-value = 0.06059
## alternative hypothesis: two.sided
